# app/

Vite + React + TypeScript frontend and the loopback AI backend for
Unlayer Agent Lab. See the repository root `README.md` and
`CONTRIBUTING.md` — start there, not here.

- `npm install`, `npm run dev` — keyless development server.
- `npm run server` — local AI backend (needs `app/.env`; loopback only).
- `npm run test:run`, `npm run build`, `npm run lint` — required gates.
